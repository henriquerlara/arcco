# Pasta de marca oficial

Substitua o símbolo provisório pelo arquivo oficial da ARCCO:

1. Coloque o SVG/PNG oficial nesta pasta (ex.: `logo-arcco.svg`).
2. Atualize `apps/web/src/components/marca/MarcaArcco.vue` para usar o arquivo oficial em vez do SVG inline dos arcos.
3. Mantenha o texto “ARCCO” e o subtítulo opcional “Inteligência Comercial”.

Não invente uma nova identidade visual — use apenas os assets oficiais.
